# Calibration

## 目的

キャリブレーションでは、iPhoneのAR空間と実物の脳模型の位置を対応させます。

最終的に必要なのは、指先3D座標を脳模型座標系へ変換し、どの部位に近いかを判定できる状態です。

## iPhone固定位置

iPhone 12 Proは展示中に動かないよう固定します。

推奨:

- 三脚または固定治具を使う
- 背面カメラとLiDARが脳模型全体を見られる位置に置く
- 来場者の手が脳模型とカメラの間に入りすぎない角度にする
- ケーブル給電する
- 展示中に画角がずれないよう、固定具に目印を付ける

## 脳模型の位置合わせ

初期段階では、脳模型を単純形状として扱います。

- 楕円体
- 箱

脳模型の中心、幅、高さ、奥行きをキャリブレーション値として持ちます。

```json
{
  "brainCenter": { "x": 0.0, "y": 0.0, "z": -0.8 },
  "brainSize": { "x": 0.18, "y": 0.13, "z": 0.15 },
  "shape": "ellipsoid"
}
```

単位はメートルを想定します。

## LiDAR深度差によるキャリブレーション

現在の実装では、手作業の中心合わせに加えて、LiDAR深度差から脳模型の位置とサイズを推定できます。

基本方針:

1. iPhoneを固定する
2. カメラ中心から半径50cm程度の範囲に何も置かない
3. 空の深度マップを `Capture Empty Baseline` で保存する
4. 決めた向きで脳模型を置く
5. `Calibrate Brain From Depth` で、空状態より手前に出てきた深度差を脳模型候補として抽出する
6. 候補ピクセルの中心・幅・奥行き・高さを計算し、楕円体キャリブレーション値へ反映する
7. AR画面上の半透明楕円体と実物の重なりを見て、必要に応じて手動で微調整する

この方式は、脳模型の正確な部位形状を認識するものではありません。現段階では「実物脳模型に近い位置・大きさの楕円体」を自動で置くための補助機能です。詳細な手順は `depth-based-calibration.md` を参照してください。

## 最初のキャリブレーション方法

Phase 1では、LiDAR深度差による粗い自動キャリブレーションと、手作業の微調整を組み合わせます。

1. iPhoneを固定する
2. 脳模型を置く前に、空状態の深度を記録する
3. iPhoneアプリでARセッションを開始する
4. 脳模型を決めた向きで置く
5. LiDAR深度差から楕円体の中心・幅・奥行き・高さを推定する
6. 脳模型の左右端、上端、下端、前後方向の目安を手動で微調整する
7. 楕円体または箱として脳模型の近似形状を保存する
8. PC側でデバッグ表示し、指先との距離が妥当か確認する

## 部位ラベル

初期段階では座標範囲でラベルを決めます。

例:

- x < 0: 左半球
- x >= 0: 右半球
- zが前方: 前頭葉
- zが後方: 後頭葉
- yが下側かつ左右外側: 側頭葉

これは展示用の暫定判定です。医学的な正確性よりも、体験として安定して反応することを優先します。

## 将来のSTL / OBJ対応

最終段階では、実際の脳模型に対応するSTL / OBJを使います。

必要になるもの:

- 模型と同じスケールの3Dモデル
- 部位ごとに分割されたメッシュ、または頂点/面へのラベル
- 指先座標から最近傍表面点を探す処理
- 最近傍点の部位ラベルを返す処理
