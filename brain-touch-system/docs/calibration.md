# Calibration

## 目的

キャリブレーションでは、iPhoneのAR空間と実物の脳模型の位置を対応させます。

最終的に必要なのは、指先3D座標を脳模型座標系へ変換し、どの部位に近いかを判定できる状態です。

## iPhone固定位置

iPhone 12 Proは展示中に動かないよう固定します。

推奨:

- 三脚または固定治具を使う
- 背面カメラとLiDARが脳模型全体を見られる位置に置く
- 来場者の手が脳模型とカメラの間に入りすぎない角度にする
- ケーブル給電する
- 展示中に画角がずれないよう、固定具に目印を付ける

## 脳模型の位置合わせ

初期段階では、脳模型を単純形状として扱います。

- 楕円体
- 箱

脳模型の中心、幅、高さ、奥行きをキャリブレーション値として持ちます。

```json
{
  "brainCenter": { "x": 0.0, "y": 0.0, "z": -0.8 },
  "brainSize": { "x": 0.18, "y": 0.13, "z": 0.15 },
  "shape": "ellipsoid"
}
```

単位はメートルを想定します。

## 最初のキャリブレーション方法

Phase 1では手作業のキャリブレーションを採用します。

1. iPhoneを固定する
2. 脳模型を展示台に固定する
3. iPhoneアプリでARセッションを開始する
4. 脳模型の中心点を画面上で指定する
5. 脳模型の左右端、上端、下端、前後方向の目安を指定する
6. 楕円体または箱として脳模型の近似形状を保存する
7. PC側でデバッグ表示し、指先との距離が妥当か確認する

## 部位ラベル

初期段階では座標範囲でラベルを決めます。

例:

- x < 0: 左半球
- x >= 0: 右半球
- zが前方: 前頭葉
- zが後方: 後頭葉
- yが下側かつ左右外側: 側頭葉

これは展示用の暫定判定です。医学的な正確性よりも、体験として安定して反応することを優先します。

## 将来のSTL / OBJ対応

最終段階では、実際の脳模型に対応するSTL / OBJを使います。

必要になるもの:

- 模型と同じスケールの3Dモデル
- 部位ごとに分割されたメッシュ、または頂点/面へのラベル
- 指先座標から最近傍表面点を探す処理
- 最近傍点の部位ラベルを返す処理
