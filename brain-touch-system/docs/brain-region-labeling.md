# Brain Region Labeling

## 目的

このドキュメントは、仮の楕円体判定から、実際の脳模型 STL / OBJ に基づく部位判定へ移行するためのラベル設計方針をまとめます。

このシステムでは、医学的な厳密性よりも、展示中に安定して「どこを触ったか」を返せることを優先します。ただし、来場者や運営者に見せる名称として明らかに誤った脳部位名にならないようにします。

## 共有ラベル定義

部位ラベルの基本辞書は `shared/brain-regions.json` に置きます。

各部位は以下を持ちます。

| Field | Description |
| --- | --- |
| `id` | JSONイベントの `region` に入る安定ID |
| `labelJa` | PCダッシュボードや演出で使う日本語表示名 |
| `labelEn` | 将来の英語表示やデバッグ用表示名 |
| `descriptionJa` | 展示上の扱い方を含む説明 |
| `defaultSurfaceTypes` | その部位が出やすい面。初期判定やデバッグ色分けに使う |
| `visualCue` | PC表示、ログ確認、演出連携で使う色や短縮ラベル |

現時点の対象部位は以下です。

- `left_frontal_lobe`: 左前頭葉
- `right_frontal_lobe`: 右前頭葉
- `left_parietal_lobe`: 左頭頂葉
- `right_parietal_lobe`: 右頭頂葉
- `left_temporal_lobe`: 左側頭葉
- `right_temporal_lobe`: 右側頭葉
- `occipital_lobe`: 後頭葉
- `cerebellum`: 小脳
- `brainstem`: 脳幹
- `unknown`: 不明

## STL / OBJ へのラベル付け方針

最終的には、模型と同じ座標系・スケールの STL / OBJ を用意し、メッシュ表面に部位ラベルを対応付けます。

候補となる管理方法:

1. 部位ごとに別メッシュファイルを持つ
2. 1つの OBJ 内で material / group name に部位IDを入れる
3. 別JSONで三角形インデックス範囲と部位IDを対応付ける
4. 別JSONで空間分割領域と部位IDを対応付け、最近傍点の部位を返す

初期実装では、編集と検証がしやすい `部位ごとの別メッシュ` または `OBJ group name` を優先します。STLは標準的に部位名を持ちにくいため、複数STLに分けるか、外部JSONで対応表を持つ方針にします。

## 判定の基本手順

将来のSTL / OBJ判定は、以下の流れを想定します。

1. 指先の `indexTip3D` を ARKit world space で取得する
2. キャリブレーション結果を使って brain model coordinate へ変換する
3. 脳模型メッシュ表面との最近傍点を探す
4. 最近傍点の距離がしきい値以内なら接触候補にする
5. 最近傍点が属する部位IDを `shared/brain-regions.json` で表示名へ変換する
6. 境界付近、低信頼度、深度不安定時は `unknown` に落とす

## 展示向けの安定化ルール

医学的に細かい境界よりも、以下を優先します。

- 触った場所が多少ぶれても同じ部位になりやすいこと
- 境界付近でラベルが高速に切り替わらないこと
- 観客が見て納得しやすい大きめの領域にすること
- 小脳や脳幹など、模型上で触りにくい部位は無理に判定しないこと
- 信頼できない入力は `unknown` にすること

特に部位境界では、最近傍距離だけでなく、直近数フレームの多数決や dwell time を使います。境界から一定距離以内の場合は、信頼度を下げるか `unknown` にします。

## キャリブレーションとの関係

部位ラベル判定の前提は、iPhoneで取得した指先3D座標と実際の脳模型座標が合っていることです。

必要なキャリブレーション:

- 模型中心位置
- 模型スケール
- 模型の向き
- iPhone固定位置とARKit world spaceの関係
- STL / OBJモデルの原点と実物模型の対応

キャリブレーションが不十分な状態では、部位ラベルを細かくしても判定は安定しません。まずは楕円体で中心・サイズ・向きを合わせ、その後にメッシュラベルへ置き換えます。

## 実装しないこと

この段階では、まだ以下は実装しません。

- STL / OBJ読み込み
- メッシュ最近傍探索
- 部位別メッシュの表示
- 医学的に厳密な脳溝・脳回レベルの分類

このドキュメントと `shared/brain-regions.json` は、後続実装で使うラベルIDと表示名の土台です。
